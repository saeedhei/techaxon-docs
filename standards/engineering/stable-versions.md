# Stable Version Rule

Use **LTS (Long-Term Support) versions** of runtimes, frameworks, and major dependencies whenever an LTS version is available.

For Docker images, prefer using a **stable version one major release behind the latest LTS** when appropriate, rather than immediately adopting the newest version.

The goal is to prioritize **stability, compatibility, and predictable deployments** over using the newest available version.

Any exception should have a clear technical reason.
