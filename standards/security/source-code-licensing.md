# Source Code & Licensing Rule

The Techaxon source code is proprietary and must only be used under a valid license.

The current code is licensed under the owner's license. Once Techaxon is officially registered, the applicable Techaxon license will govern the project.

Source code must not be shared, copied, or provided to others without proper authorization.

Requests for source code access without proper authorization must be declined to ensure data privacy and maintain project confidentiality.
